# Presupuesto adicional
Imán del lienzo — ALEI


Este presupuesto suma una función al panel de administración del sitio. No reemplaza el presupuesto de la web.


1. Alcance — qué se construye

En el posicionamiento libre del admin (Works y Colabs), al acercar una imagen a otra:

- se engancha al borde o al centro de la vecina, para quedar alineadas;
- puede quedar del mismo tamaño;
- puede quedar a la misma distancia que el hueco que ya existe entre otras imágenes.

Mientras se acomoda, aparece una guía breve que muestra a qué se pegó. Hay un control Imán para activarlo o desactivarlo. Con el imán apagado, las imágenes se mueven como ahora.

La posición se guarda igual que hoy. En la web pública las obras se ven donde el cliente las dejó.


2. Entrega

Dentro de los 7 días hábiles desde la confirmación de este adicional.

Queda incluida una vuelta de ajustes después de que el cliente lo pruebe en el admin, siempre dentro de lo descrito arriba.


3. Qué no incluye este presupuesto

- Un botón que ordene de una vez toda una fila o toda la página.
- Rotar imágenes.
- Cambios de diseño del sitio público.
- Otras funciones del admin fuera de este enganche.
- Cualquier cambio que no esté escrito en este documento. Se presupuesta aparte.

Qué cubre

El cliente acomoda las obras acercándolas entre sí, sin medir a ojo ni pedir que alguien las alinee. El imán se puede apagar cuando la composición pide otra cosa.
